SAFARIA Tours & Travels · v2 block

Paste-ready GHL code

One Custom Code element that adds the v2 motion, 3D route overlay and analytics layer on top of your existing SAFARIA page. Your current page keeps working; delete the element to roll back.

  1. Clone the page first. In GHL: Sites → Websites → your site → the page's ⋮ menu → Clone. Work on the clone.
  2. Add a Custom JS/HTML element directly below your existing SAFARIA code element.
  3. Copy the code below with the gold button, paste it into that element, and save.
  4. Set your phone number: near the top of the code, change phone: "+8801674178437" to your official WhatsApp number if it differs.
  5. Open Preview, not the editor. GHL doesn't run custom scripts inside the builder canvas. Check desktop and phone, then publish the clone.
Seeing nothing move? Your Windows "Animation effects" setting is off (Settings → Accessibility → Visual effects). The block respects that setting, so on your PC it shows only the still gold routes over the hero globe. Turn the setting on, or open the page on your phone, to see the full motion. To confirm the block loaded, right-click the page → Inspect → Console: you'll see [SAFARIA v2] active.

What the block does

Hero entrance and scroll reveals (anime.js 4 and Motion 11), image wipes, parallax on the lagoon image, a magnetic hero button and tilting destination cards, gold route lines from Dhaka over the painted hero globe (three.js, desktop and tablet only), and WhatsApp and call click tracking in your analytics. Visitors with reduced motion get no animation and a still route overlay.
