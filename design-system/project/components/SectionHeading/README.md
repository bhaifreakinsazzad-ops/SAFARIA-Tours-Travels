Opens each section: an uppercase eyebrow with a gold rule, a display h2, and an optional lead.

- The markup is `p.sf-eyebrow`, then `h2` (wrap one phrase in `<em>` for the gold italic accent), then `p.sf-lead`.
- Add `data-sf-reveal` to each element for the scroll reveal (`Safaria.Motion.reveal(root)`).
- **Do:** limit h2 to two lines and lead to 470px wide or less.
- **Don't:** put gold on more than one phrase, or use the eyebrow as the only heading.
