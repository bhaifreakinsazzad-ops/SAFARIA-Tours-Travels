The service index, with air ticketing listed first and marked as primary.

- The markup is `nav.sf-service-list > a`, each containing an icon, `<span><strong>title</strong><small>line</small></span>` and an arrow icon. Add `.sf-primary` to the air ticketing row only.
- Add `data-sf-stagger` to the nav to get the staggered reveal.
- Order: air ticketing, visa, hotels, tours, corporate, B2B. Each row links to its own enquiry, not a generic form.
- **Don't:** promise outcomes in the sub-line (no "guaranteed visa").
