The FAQ, built on native `<details>`/`<summary>` so it works with no JavaScript and with screen readers.

- The markup is `.sf-accordions > details > summary (text + chevron icon) + .sf-answer`. Mount it with `Safaria.Accordion.mount(root)` to animate height (skipped under reduced motion).
- Answers state the honest limits: enquiry is not a booking, visas are decided by the authorities, and fares are quoted, not live.
